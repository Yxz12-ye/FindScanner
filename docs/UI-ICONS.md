# 界面图标清单

已接入提供的 14 个 SVG 图标。原稿由 `docs/ico` 移至 `app/artwork/icons/`，运行时使用 `app/src/main/res/drawable/ic_*.xml` 原生矢量资源；所有图标随 Material 3 动态取色和深色主题着色。

更新原稿后执行 `python tools/generate_ui_icons.py`，重新生成 Android 矢量资源。转换保留路径、圆、圆角矩形、线条、圆端点及 2 px 线宽；SVG 中的青色只用于原稿预览，运行时由界面主题决定颜色。

| 原稿文件名 | 图标含义 | 使用位置 |
| --- | --- | --- |
| radar.svg | 雷达 / 扫描标志 | 顶栏 FindScanner 标志、权限页插图 |
| wifi.svg | Wi-Fi | 权限页、信号详情 |
| bluetooth.svg | 蓝牙 | 权限页、信号详情 |
| location.svg | 定位图钉 | GPS 权限、位置输入、开始推理 |
| history.svg | 时钟 / 历史 | 历史入口、待上传记录 |
| check.svg | 对勾 / 成功 | 全部允许、已上传记录 |
| arrow-back.svg | 返回箭头 | 页面顶栏 |
| arrow-forward.svg | 前进箭头 | 连接并继续 |
| chevron-right.svg | 向右展开 | 采集记录、历史入口 |
| more-vertical.svg | 圆形省略号（按提供的图形） | 顶栏更多菜单 |
| refresh.svg | 刷新 | 推理结果刷新 |

图标均为 24×24 单色线条；雷达图标在权限插图中放大显示。返回、前进及展开箭头在 RTL 布局中自动镜像。

## 紧凑版调整

- 页面间距：20 dp → 12 dp；卡片内边距：20 dp → 14 dp，内部间距：16 dp → 10 dp。
- 主按钮高度：56 dp → 48 dp，保留 Material 3 点击区域。
- 权限插图高度：170 dp → 100 dp；两个次要操作并排展示。
- 页面说明和大标题缩小一级，推理准备标题去除强制换行。
- 列表行上下内边距：16 / 18 dp → 10 dp，统计卡片与概率圆环同步缩小。
- 保留动态取色、深色主题、全部 mock 数据和页面跳转行为。

## 页面布局

- 权限页与连接页主体居中；采集、推理准备页及推理结果主体靠上。
- 主操作统一固定在底部，输入法弹出时避让键盘。
- 采集记录独立使用 LazyColumn，展示全部轮次；统计卡片固定在列表下方。
- 每轮详情的信号列表独立滚动，统计摘要、筛选器和 GPS 结果固定在列表外；切换筛选后回到列表顶部。
