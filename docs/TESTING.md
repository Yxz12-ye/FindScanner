## 1. debug 模式验收

### 历史页面返回回归

- 在连接页未连接时，分别从右上角打开采集历史、推理历史，再按系统返回键或左上角返回，应回到连接页。
- 曾连接成功后重新进入连接设置，重复上述操作，也应回到连接页，不能因为保留旧连接配置而进入主页。
- 连接页 → 采集历史 → 采集详情 → 返回 → 采集历史 → 返回 → 连接页；推理历史及其结果详情遵循相同路径。
- 在两个历史列表之间切换后返回，仍回到最初的入口页；从已连接的主页打开历史，返回主页。
- 历史页导航由 `ScannerNavigationTest` 覆盖，本次仅执行本地检查，手机验收由用户自行进行。

1. 启动后申请定位与附近设备权限；也可选择允许部分数据继续。永久拒绝时通过系统权限设置重新授权。
2. 服务器填 `debug`，区域和设备 ID 自行填写，点击连接。应直接进入主页，显示“本地调试”，不要求服务器在线。首尾空白及大小写不影响 debug 识别。
3. 填写中文位置或 `(1,2)`，点击“采集准备”。开始前应没有模拟历史、MAC、GPS 或概率。
4. 开始采集后立即启动传感器，完整 10 秒结束生成首条记录，以后约每 10 秒新增。查看真实 Wi-Fi/BLE 数量、时间及“仅本地 · debug”状态；无信号也生成带原因的记录。
5. 进入详情筛选全部/Wi-Fi/BLE，确认 RSSI 由强到弱；检查观测时间、缓存年龄、fresh、新/旧 Wi-Fi 状态、GPS 或缺失原因。debug 记录没有上传重试入口。
6. 暂停在半轮内，等待超过 10 秒，记录不增加；继续后重新等完整 10 秒，不补造暂停期间记录。
7. 开始后切后台或离开会话，采集停止；回前台不会自动继续。进入同一会话详情可继续采集。旋转屏幕保留 ViewModel 中的会话。
8. 运行中屏幕常亮，暂停后恢复系统行为。检查轮次、倒计时与记录周期一致。
9. 位置推理按钮应禁用，且明确提示 debug 下不可用；历史只允许查看。
10. 重启进程，再次连接后历史仍在，采集不会自动恢复。连接真实服务器后 debug 历史仍仅本地，不补传。

## 2. 正常服务器与补传

后端先按 `API.md`、`openapi.yaml` 实现三个端点；客户端不提供训练服务或定位算法。

1. 验证不带协议的 IP:端口、显式 HTTPS、无效地址、非 1 协议。连接成功才持久保存配置。Android 17 请求局域网权限后再连接真实服务器。
2. 完成一轮采集，服务端写入后回显相同 ID 和 accepted；详情状态变为已上传。
3. 模拟服务端已存储但响应丢失；客户端重试相同 ID 和 JSON，后端返回 duplicate，数据库不能多一条。
4. 断网后持续采集，记录仍先入库。网络恢复并保持前台时按退避补传，上传慢不得拖慢 10 秒采样周期。
5. 让服务端返回 400/409、408/429/503、异常 JSON 或错误确认 ID，分别检查不自动重试/退避重试和详情失败原因。手动重试不得改变内容。
6. 保留真实服务器 A 的待上传记录，切 debug，A 不再收到补传。再连接真实服务器 B，原记录仍发往 A，B 只接收创建时属于 B 的记录。debug 记录永不上传。
7. 从更多菜单打开本地采集/推理历史；清理前应明确告知未上传和 debug 数据数量，确认后清理，不自动删除待传数据。

## 3. 推理

1. 真实服务器正常连接后进入推理。首轮完整采样前显示等待；后端返回 ok 候选时按概率降序展示。
2. no_model、no_match 必须显示对应状态，不出现伪造概率；全无可用信号时不发送推理请求。
3. 非法概率、总和错误、重复位置、错误响应 ID 和断网应显示错误，不重发旧轮次。
4. 慢请求期间只能有一个推理请求；暂停、离开或后台之后的迟到响应不能更新 UI 或写入推理历史。
5. 暂停/历史查看应标记结果已过期；连续运行但超过收到结果后 30 秒未更新，也应标记过期。
6. 后端不得将 inference 请求写入训练样本，推理请求不包含 locationLabel。

## 4. 传感器边界

- 精确/近似/拒绝/永久拒绝/运行中撤销权限分别检查；Wi-Fi 扫描和用于定位的 BLE 不以近似定位冒充完整授权。
- Wi-Fi 开关关闭、系统定位关闭、主动扫描节流、广播失败、旧缓存、空列表。
- 蓝牙关闭、无 BLE 硬件、无广播、扫描错误；只读取广播，不配对或连接设备。
- GPS 在室内无定位、超过 60 秒旧定位、缺失高度、仅近似定位；不显示示例坐标或 0,0 占位。
- 部分数据缺失和三类全缺失均保留状态记录；页面不崩溃，后续窗口继续运行。

## 5. 倒计时与长文本布局

- 推理运行期间显示与采集页一致的采样进度条和下一轮倒计时，每个实际 10 秒采样窗口重新计时；倒计时不代表服务器响应剩余时间。
- 暂停、切后台或查看历史时，进度归零并显示已暂停；手动继续后从完整窗口重新计时。
- 采样时间、统计数值、上传地址、MAC 和信号详情保持单行，超长时可在对应文字上左右滑动查看完整内容。
- 顶部区域/设备、位置名和历史摘要超长时以省略号收尾；常用位置和信号筛选按钮整行可横向滚动。
- 使用较小屏宽、放大系统字体、长域名/IP/IPv6、长中文位置名检查：标签与值不互相挤压，时间卡片不因换行而单独增高。
- 本次仅执行本地构建、单元测试和 Lint；布局实机验收由用户自行进行。

## 7. Toast 与服务端错误

- 服务器返回例如 HTTP 404 和 `{"error":{"code":"REGION_NOT_FOUND","message":"该区域尚未创建"}}` 时，Toast 与连接页错误文字都应包含状态码及服务端原因；再次点击连接时仍应提示相同错误。
- 测试顶层 `message`、字符串 `detail`/`error`、纯文本、空响应、HTML 和无效 JSON；未知内容回退为 HTTP 状态码，不把整页错误文档显示出来。
- 地址解析失败、拒绝连接、超时、证书错误分别有相应提示；正常连接和 debug 连接有成功/调试状态提示。
- 权限拒绝、空采集位置、推理请求失败、手动加入重试队列、清理完成均提供反馈；同一连续推理错误不按每轮重复弹出。
- 自动上传错误保存在记录详情，避免多条队列同时失败时刷屏；通知只在页面前台时展示。
- `ErrorMessageTest` 使用本地替身服务验证服务器错误的提取及降级，不依赖实际后端或手机。
